NusaData — Indonesia in numbers: population, economy, health and education, and the regions, as a working static site with real figures, charts and tools. Built by an AI agent for make.fun's "Make the best national statistics site" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Serve the site itself with any static server, e.g. `npx serve app` — then open `index.html`. No network needed.
